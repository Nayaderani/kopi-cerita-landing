# Kopi Nusantara Landing

Buatkan website landing page sederhana tentang coffe shop in agar calon pelanggan yang ingin mampir ke kedai ini dapet mengetahui informasi tentang coffee shop ini, buat menyesuaikan plan markdown berikut.

# Landing Page Plan — Kopi Nusantara

## 1. Hero Section

- **Headline**: "Secangkir Cerita, Sejuta Rasa Nusantara"

- **Sub-headline**: Kalimat pendek yang menjelaskan value (kopi asli daerah, racikan khas)

- **Gambar/Background**: Foto kopi/interior cafe berkualitas tinggi

- **CTA Button**: "Pesan Sekarang" atau "Lihat Menu" → scroll ke menu/WhatsApp

- **Navbar**: Logo + menu (Beranda, Tentang, Menu, Testimoni, Kontak)

## 2. About Us Section

- **Judul**: "Tentang Kopi Nusantara"

- **Cerita singkat**: Asal-usul brand, filosofi (mengangkat kopi lokal Indonesia)

- **Value proposition**: 3 poin unggulan

  - Biji kopi pilihan dari petani lokal

  - Racikan tradisional & modern

  - Suasana nyaman untuk nongkrong/kerja

- **Foto pendukung**: Interior toko, proses roasting, atau tim barista

## 3. Testimoni

- **Judul**: "Kata Mereka Tentang Kami"

- **Format**: Card/carousel berisi

  - Foto/avatar pelanggan

  - Nama & lokasi

  - Rating bintang

  - Kutipan singkat testimoni

- Minimal 3–6 testimoni untuk kredibilitas

## 4. Tombol WhatsApp

- **Floating button** di pojok kanan bawah (sticky, selalu terlihat)

- **Icon**: WhatsApp hijau khas

- **Fungsi**: Klik langsung buka chat WA dengan pesan default

  - Contoh: "Halo, saya ingin pesan kopi di Kopi Nusantara"

- Bisa ditambahkan juga sebagai CTA sekunder di Hero Section

## 5. Footer

- **Logo & tagline** singkat

- **Kontak**: alamat, nomor telepon, email

- **Jam operasional**

- **Sosial media**: Instagram, Facebook, TikTok (icon links)

- **Copyright**: "© 2026 Kopi Nusantara. All rights reserved."

- **Peta lokasi** (opsional, embed Google Maps)

**Tech stack saran**: HTML/CSS/JS sederhana, atau React + Tailwind untuk hasil lebih modern & responsif.
